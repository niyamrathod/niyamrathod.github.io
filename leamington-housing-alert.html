Side Project

Leamington
Housing Alert

A scraper that watches independent Leamington Spa letting agents for new student houses and emails a digest the moment something matches my criteria. I built it because refreshing agent websites by hand every day during house-hunting season got old fast. It leaves out Rightmove, Zoopla, SpareRoom and OnTheMarket on purpose, since their terms of use prohibit automated scraping, so those get their own native saved-search alerts set up separately. It runs on a GitHub Actions schedule with no server and no database. Git itself is the only persistence layer.

  • Web Scraping
  • GitHub Actions
  • Automation
  • BeautifulSoup
  • Python
 View the repo
Why I built this

Most student housing gets snapped up within days of listing, and I was manually re-checking a handful of agent sites every morning during the search. This just does that checking for me and only interrupts me when something actually matches - price, bedroom count, and area.

How it stays reliable unattended

Every listing seen gets recorded with an atomic file write so a crash mid-run can't corrupt the dedup state, and every successful run pings a healthchecks.io heartbeat - if the scheduled job ever silently stops firing or starts erroring, I get emailed automatically instead of just not noticing.

Get the alerts

Leave your email and I'll add you to the recipient list by hand - this is a small tool for a few close friends house-hunting in Leamington Spa, not an open public mailing list.

No spam, just house alerts. You can ask to be removed any time.
